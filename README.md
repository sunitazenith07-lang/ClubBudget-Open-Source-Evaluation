# RewardBook — Rewards Rules & Repeat-Transaction Alerts

Zenith School of AI | 24-hour individual Python evaluation

This simulated rewards service is inspired by common fintech loyalty products. It is not CRED's internal code and uses synthetic data only.

## Start
Read `STUDENT_PROBLEM_STATEMENT.md`, then run `python -m pip install -r requirements-dev.txt`, `python -m pytest -q`, and `python -m main`.

The starter intentionally has defects. Visible tests give feedback; do not delete, skip, weaken or bypass them. GitHub Actions runs on pushes and pull requests. Check the PR's Checks tab for the outcome. Fork this repo, submit a PR to the original, and do not merge it.

Files: `service.py` (rules/events), `models.py` (account model), `fixtures.py` (synthetic examples), `tests/test_contract.py` (visible checks), `.github/workflows/tests.yml` (CI). Read `CONTRIBUTING.md` for the individual-work and AI-use rules.
